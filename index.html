Цвета тааджвида

Подробные правила: вкладка «Тааджвид». Цвета видны, когда слова открыты и кнопка 🎨 включена.

Как пользоваться

🎙 Начать: читайте вслух непрерывно — программа идёт по всей странице (не только один аят). Слова открываются по мере чтения (зелёное — верно, красное — другое слово, жёлтое — пропуск). ⏮ ⏭ — аяты. ↺ — сначала. ✓ — выученное. 🙈 — текст виден / скрыт / подсказка. Нажмите на скрытое слово, чтобы подсмотреть. ▶ — аудио. Номер аята ﴿٣﴾ — проиграть его.

✨ Верхняя панель закреплена при прокрутке. Бисмиллях учитывается. Экран не гаснет. Распознавание смягчено под арабскую речь (короткие обрывки игнорируются, поиск вперёд по странице).
